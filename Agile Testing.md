## Agile Testing
				*Agile testing is a software testing practice that integrates testing continuously throughout the entire development lifecycle, 
				*rather than treating it as a separate phase at the end. In this approach, 
	*Quality Assurance (QA) teams, developers, and product owners collaborate in real-time to catch bugs early, validate user requirements, 
	*and deliver high-quality software in short, iterative cycles called sprints
	
	
Key Principles of Agile Testing
#Continuous Testing: 
Testing happens constantly alongside requirements gathering, design, and coding.

#Shared Responsibility: 
The entire team—not just the designated QA team—is responsible for product quality.

#Continuous Feedback: 
Testing provides instant feedback to developers, allowing code to be fixed immediately.

#Less Documentation: 
Teams prioritize working software over exhaustive, static test plan documents.
