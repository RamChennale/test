##Jira Xray
*Jira Xray is a native test management app for Jira. 
*It helps teams plan, run, and track testing right inside Jira issues. You can link tests to requirements and bugs to see full quality coverage.

Core Purpose: Xray brings test management into Jira so testers and developers work in one place.
***Jira Xray Key Features
- Jira issue: It uses Jira issue types like Test, Test Set, Test Execution, and Test Plan and put it togather linked as per Sprint clusure requirment.
- BDD Support: It supports BDD (Behavior-Driven Development) using Cucumber features and step definitions to describe the bussiness requirment.
- Reporting: It shows built-in differecnt reports views Sprint velocity status report and test coverage metrics.
- Automation: It connects via REST API or CI/CD plugins to push automated test results
